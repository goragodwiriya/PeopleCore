1. Core HRIS / Employee Database
โมดูลนี้เป็นฐานข้อมูลคนในองค์กร ทุกโมดูลอื่นจะใช้มันเป็นศูนย์กลาง

โครงสร้างข้อมูลพนักงาน
ข้อมูลส่วนตัว: ชื่อ–นามสกุล, เลขพนักงาน, วันเกิด, ติดต่อ, ที่อยู่
ข้อมูลงาน: ตำแหน่ง, แผนก/หน่วยงาน, สายการบังคับบัญชา, สถานะจ้าง (ประจำ, สัญญาจ้าง, ชั่วคราว)
ประวัติการทำงาน: วันที่เริ่มงาน, วันสิ้นสุดงาน (ถ้ามี), ประวัติการเลื่อนตำแหน่ง, ปรับเงินเดือน
ข้อมูลอื่น: ประกัน, สิทธิ์สวัสดิการ, หมายเหตุ HR
การจัดการโปรไฟล์
เพิ่ม/แก้ไข/ย้าย/ยกเลิกพนักงาน
ปรับตำแหน่ง/หน่วยงานย้อนหลัง (เก็บ history)
แนบเอกสารสำคัญ (สัญญาจ้าง, ใบสมัคร, ใบอนุญาต, ใบเตือน ฯลฯ)
โครงสร้างองค์กร
ตาราง/หน้าจัดการหน่วยงาน (แผนก, ฝ่าย, BU)
โครงสร้างสายบังคับบัญชา (manager–subordinate)
ระดับตำแหน่ง (job grade/level)
สิทธิ์และบทบาทผู้ใช้
Role หลัก: Admin ระบบ, HR, Manager, Employee
การแม็ปผู้ใช้กับพนักงาน (account ↔ employee record)
การกำหนดสิทธิ์เข้าถึงข้อมูล (เช่น HR เห็นทุกคน, Manager เห็นเฉพาะทีมตัวเอง)
